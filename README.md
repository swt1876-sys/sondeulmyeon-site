# sondeulmyeon.kr — 손들면 홈페이지

손들면 앱의 공개 홈페이지예요. (앱 코드는 비공개 저장소 `loan-match`에 있어요)

| 파일 | 내용 |
| --- | --- |
| `index.html` | 첫 화면 (서비스 소개) |
| `privacy.html` | 개인정보처리방침 — 플레이스토어·앱스토어 등록에 필요 |
| `terms.html` | 이용약관 |
| `CNAME` | 이 사이트를 `sondeulmyeon.kr` 주소로 연결 |

노란색으로 표시된 `[ ]` 칸(운영자 이름, 문의 이메일, 시행일)은 출시 전에 채워 주세요.
